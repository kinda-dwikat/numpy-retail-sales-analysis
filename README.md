# numpy-retail-sales-analysis
# Retail Sales Analysis Using NumPy

## About the Project
This is a simple Python project I built while learning NumPy and practicing data analysis.

The project analyzes sales data for a small store that sells four products: laptops, mice, keyboards, and monitors.

## What the Project Does
- Calculates total units sold for each product and each day.
- Finds the best-selling product.
- Calculates daily revenue and total weekly revenue.
- Identifies the product generating the highest revenue.
- Finds days when more than 3 laptops were sold.
- Ranks products based on their revenue.
- Calculates each product's percentage contribution to total revenue.

## Tools Used
- Python
- NumPy

## NumPy Concepts I Practiced
- Arrays and 2D arrays
- `axis=0` and `axis=1`
- Boolean masking and indexing
- Broadcasting
- `np.argmax()`
- `np.argsort()`
- `np.round()`

## How to Run
1. Make sure Python and NumPy are installed.
2. Download the `store_sales_analyzer.py` file.
3. Run the Python file to see the analysis results.
